# slasm
## compile
Скомпилировать текст в байткод инструкций, меток и коментариев.

### tokenizer
Токенизатор превращает текст программы в массив строк-токенов.

Разделители - пробел, '\n', '\t', '\r'. Сами в токены не попадают.

'(' и ')' - всегда отдельные токены, даже без пробелов вокруг них.

Обычные символы (не разделитель, не скобка, не внутри ';...;') копятся в один токен, пока не встретится разделитель или скобка.

#### ';...;' блоки
Всё между двумя ';' - один токен целиком, вместе с обеими ';'. Внутри может быть что угодно, кроме '(' и ')' и разделителей (пробел и т.д.).

Разделитель внутри ';...;' - разные токены, а не ';...;'-блок.
Незакрытый ';...;' (до конца программы не встретилась вторая ';') - просто токен.

### parser
Парсер превращает массив токенов из токенизатора в массив инструкций, массив меток и массив комментариев.

'(' - кладёт следующий сразу за ней токен в отдельный стек операторов. То есть после '(' всегда должен идти ровно один токен - имя оператора.

')' - снимает верх стека операторов и добавляет его в инструкции как есть, без аргументов. Скобки не группируют выражение с аргументами, они просто откладывают запись оператора на потом.

Незакрытая '(' (нет токена сразу после неё, или к концу программы стек операторов не пуст) - ошибка парсинга.

Любой обычный токен (не '(', не ')', не ';...;') превращается в две инструкции: 'push' и сам этот токен. То есть литерал в SLASM - это всегда неявный 'push'.

#### ';...;' токены
Если внутри, сразу после первой ';', и перед последней ';' есть '-' с обеих сторон (то есть токен вида ';-name-;') - это метка, привязывается к позиции следующей ещё не добавленной инструкции (1-базирован).
Кидать ошибку если 'встретилась метка без имени. (например ';--;', ';-;')

Иначе (';текст;') - это комментарий, тоже привязывается к позиции 1-базировано, на исполнение не влияет.
Одиночный токен ';' считать пустым коментарием.

## vm
Все это строки, числа и булевые значения тоже.
Все должно быть 1 базировано. (если не указано инное)

### instructions
instruction pointer при старте = 1.
Массив инструкций это массив из строк который создаеться 1 раз, и может быть изменен операторами SO\CO.
Если инструкция количество инструкций + 1, программа завершаеться.
Оператор 'CO' добавляет пустую инструкцию '' в конец массива.
Оператор 'SO' принимает два аргумента: число (ip) и строка (new op). Пример '(SO 12 +)'. Напрямую изменяет массив инструкций по ip.
'iget' - получить конкретную инструкцию из текущей программы. Если за пределами, возвращает ""
'i' - текущая инструкция (ip самой инструкции 'i').
'inum' - возвращает количество инструкций в программе.

> Виртуальные машины не обязаны поддерживать операторы 'SO' и 'CO'.

### stack
Стек это массив из строк, заполняеться виртуальной машиной при исполнении программы (при старте пустой).

'clearstack' - полностью очищает стек.
'_' - добавляет пустую строку "" в стек.
'getstack' - позволяет получить из стека конкретное значение, по номеру. принимает один аргумент.
'numstack' - возвращает рамер стека. (без своего собственного значения в подсчёте)
'cstack' - принимает два значения. число и строку. позволяет заменить конкретный елемент в стеке на другой.

> Виртуальные машины обязаны поддерживать операторы 'clearstack' и '_'. Остальные не обязательны.

#### Stack underflow
Если для какогото оператора нету значения, то виртуальная машина может повести себя двумя случаями:
Ошибка и остановка программы с причиной.
Передать оператору пустую строку '' вместо сломаного аргумента.

#### Stack overflow
Стек должен быть ограничен 20000, или более. Если нет или меньше, явно указать.
Возможное поведение виртуальной машины:
Выбросить ошибку.

### labels
Массив меток, ето массив данных о том, как названа та, или инная инструкция. Синтаксис ";-name-;". Создаються только при парсинге. Несколько меток могут занимать один ip.
Получить ip к которому привязана метка '(gln your_label)'. 'gln' это слой совместимости, чтобы 'jump' и '?' не принимали имя метки сами.

### boolean
Булевые значения, это просто строка 'true' или 'false'.
Оператор '!' принимает любое значение, и возвращает 'true'. Возвращает 'false' только если ему на вход подали 'true'.
Оператор '&' принимает два булевых аргумента и проверяет, оба ли равны строке 'true', если да, возвращает 'true', иначе 'false'.
Оператор '\' принимает два булевых аргумента и проверяет, равен ли хоть один аргумент строке 'true', если да, возвращает 'true', иначе 'false'.
Оператор '=' принимает два аргумента и проверяет, равны ли аргументы (со строками тоже работает), если да, возвращает 'true', иначе 'false'.
Операторы '<' и '>' работают также как и оператор '=', но не работают со строками.

### numbers
Просто строки чисел.
Ески какойто оператор принимает только целое число, то если передать ему дробное, он просто округлит в меньшую сторону (1.6 превратиться в 1, и так далее)

### arithmetic
Деление '/' на 0 возвращает 'Infinity' строку. 
'%' остаток от деления возвращает 'NaN' строку при 0.
Оператор '?*' принимает два числовых аргумента и возвращает случайное число между ними (min и max включительно оба);

### memory
Операторы 'W' и 'R' позволяют запоминать значения, не оставляя их на стеке.

(W 1 n) - записать значение n в ячейку 1.
(R 1) - прочитать из ячейки 1.

Номер ячейки должен быть числом >=1 и =<19999.

Чтение из регистра в который не писали возвращает 0.

Если пишут вне разрешенного диапазона, ничего не делать.

> Виртуальные машины должны поддерживать номера более 19999, но это не обязательно.

### string manipulation
Существует 4 базовых оператора для манипуляции строками.
'~' - принимает 2 аргумента и склеивает их вместе. Без пробела.
'char' - принимает 2 аргумента. Первый это число, а второй это строка. Возвращает строку, буква из строки.
'rep' - принимает 2 аргумента. Первый это число, а второй это строка. Возвращает строку, повторяет строку, без пробела.
'JOIN' - берет весь стек, склеивает с пробелом, и возвращает ету строку. Не чистит стек после склейки.

#### L&S
Также есть оператор 'L' и 'S'.
Пример для 'L':
Получить маленькую букву 'h' - (L 8 0)
Получить большую букву 'h' - (L 8 1)
Список для 'L' - 'ABCDEFGHIJKLMNOPQRSTUVWXYZ' (чтобы получить маленькую букву, нада указывать вторым аргументом 0. А чтобы большую, то вторым аргументом 1)
Пример для 'S':
(S 0) - ' '
(S 1) - '.'
Список для 'S' - ' .,!?+-*/_…()' (Единственный 0-базированый)

##### S2
Новый оператор 'S2' был создан для замены старого 'S' на более простую вещь.
Работает как 'S', но 1-базированый, и более простой в изпользовании чем 'S'.
Список для 'S2': ' ();'.
(S2 0) - возвращает ' ', это сделано для того чтобы было просто заменить программы с 'S' на 'S2'.
(S2 1) - ' '
(S2 2) - '(', (S2 3) - ')'
(S2 4) - ';'
(S2 -1) - ''.

### io
'clog' - принимает один любой аргумент и выводит его наружу.
'q' - возвращает один аргумент от пользователя (ждет пока введут).

### jump & if
Оператор 'jump' принимает одно числовое значение, и изменяет ip на него. Оператор который находиться на ip при jump будет выполнен.
Оператор '?' принимает два значения, одно булевое, а второе числовое, проверяет равно ли булевое значение 'true'.
Если да, изменяет ip на числовое, иначе, не изменяет и продолжает исполнение дальше.
прыгать можно на 0 (но нужно перенаправить на 1) - количество инструкций + 1.
Виртуальным машинам разрешаеться:
Кидать ошибку за выход из массива инструкций.
Сгладить значение (например, прыгнули на 1000 инструкцию, когда в программе только 10 инструкций, просто завершить программу. Или другой пример, прыгнули на -12 инструкцию, то просто сделать также как с прыжком на инструкцию 0, перенаправить на инструкцию 1)

### misc operators
'wait' - принимает один числовой аргумент в милисекундах, и ждет.

'begin' и 'none' - просто пропускают одну инструкцию ('begin' оставлен для совместимости).

'throw' - принимает один строковой аргумент и завершает программу выводя ету строку как ошибку.
> Виртуальная машина не обязана поддерживать оператор 'throw'.
